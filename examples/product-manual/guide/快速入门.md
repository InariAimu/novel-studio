# Novel Studio 快速入门

Novel Studio 用于整理项目资料、编写 Markdown 和审阅修改建议。

![Novel Studio 应用图标](../assets/novel-studio.png)

## 打开并编辑文档

1. 启动带有上图图标的应用。
2. 在「项目库」选择「导入目录」，打开包含文档和图片的项目文件夹。
3. 从左侧列表选择文档。完成修改后，按 **Ctrl+S** 保存。

| 操作 | 用途 |
| --- | --- |
| 预览 | 检查标题、表格和项目内图片 |
| 导出 HTML | 生成可在浏览器中独立查看的当前文档 |
| 导出项目包 | 打包项目文件和审阅记录 |

导出前检查图片和表格。交付时可直接发送生成的 HTML 文件。
